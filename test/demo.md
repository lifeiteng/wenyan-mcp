# 文颜 CLI 工具使用演示

这是一个测试文章，用于演示文颜 CLI 工具如何将 Markdown 文件转换为适合微信公众号和知乎平台的格式。

## 主要功能

文颜 CLI 工具支持以下核心功能：

1. **多主题支持** - 提供 8 种精美主题
2. **多平台适配** - 支持微信公众号和知乎平台
3. **智能转换** - 自动处理图片、代码高亮等

## 代码示例

下面是一个简单的 JavaScript 代码示例：

```javascript
function greet(name) {
    console.log(`Hello, ${name}!`);
    return `欢迎使用文颜 CLI 工具！`;
}

greet("开发者");
```
